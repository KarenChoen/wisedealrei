# Wise Deal REI — Website

## Version 1

A simple, clean, professional website for **Wise Deal REI**, a residential real estate investment company based in Milwaukee, Wisconsin.

This first version is intentionally minimal. The goal is to establish a professional online presence now and add more content and functionality later.

## Current Website

The site currently includes:

- **Home** — Short headline and introduction
- **About Us** — Brief description of Wise Deal REI
- **Our Focus** — Three core areas:
  - Property Acquisition
  - Renovation
  - Property Management
- **Contact** — Email, location, and contact form
- **Footer** — Company name and Milwaukee, Wisconsin

There are currently **no individual property listings or placeholder properties** on the site.

## Design

The current design uses:

- Dark navy as the main color
- White backgrounds
- Subtle gold accents
- Clean, modern typography
- Simple layouts with plenty of spacing
- Responsive design for desktop and mobile

The design is intentionally professional and understated. More branding, photography, and visual elements can be added in future versions.

## Files

- `index.html` — Main website structure and content
- `styles.css` — Website design and responsive styling
- `README.md` — Project documentation

## Deployment

The planned hosting setup is:

1. **GitHub** — Website files and version control
2. **GitHub Pages** — Website hosting
3. **Custom domain** — `wisedealrei.com`
4. **Cloudflare Registrar** — Domain registration and DNS

The domain should be connected to GitHub Pages after the website is ready.

## Future Updates

The website can be expanded gradually with:

- Real property photos
- Current and past properties
- Property details
- More information about the company
- Investment opportunities
- Additional contact options
- Improved branding and logo
- SEO improvements

These features are intentionally **not included in Version 1**.

## Project Goal

Build a simple, credible online presence for Wise Deal REI first, then improve the site step-by-step as the business and property portfolio grow.
